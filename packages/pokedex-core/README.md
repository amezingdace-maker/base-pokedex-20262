# @retro-dex/core

Librería local de la Pokédex, independiente de React. Expone los tipos `Pokemon` y `Species`, la función `loadPokemon` para consultar PokéAPI, y utilidades para nombres, etiquetas de formas, tipos, estadísticas y sprites.

La aplicación la utiliza mediante npm workspaces. Desde la raíz del proyecto, `npm run build` compila primero esta librería y después la interfaz React.
